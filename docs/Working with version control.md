# Working with version control

We use GitHub and Jira to manage our Software.

These are the necessary steps to work on the Software.
1. Jira ticket to represent the work.
2. Create a branch with branch name that has Jira ticket as prefix. Eg. if Jira ticket is `AUT-1`, then branch name will be `AUT-1-work-title`
3. Every git commit message should include Jira ticket in the beginning. Eg, `AUT-1: commit message`
